# 📊 SI-Mantra
### Sistem Informasi Manajemen dan Monitoring Honor Mitra BPS Kabupaten Kediri

**SI-Mantra** merupakan aplikasi berbasis web yang dikembangkan untuk membantu **BPS Kabupaten Kediri** dalam mengelola dan memantau data mitra serta akumulasi honor berdasarkan kegiatan dan periode tertentu.

Aplikasi ini menyediakan dashboard monitoring, pengelolaan data survei, monitoring honor, serta pengaturan sistem dalam satu platform.

---

## ✨ Fitur Utama

- 📊 **Dashboard**
  - Total kegiatan/survei
  - Total mitra
  - Total honor
  - Warning honor
  - Grafik honor bulanan
  - Distribusi status honor

- 🗂️ **Master Data**
  - Daftar Kegiatan / Survei
  - Daftar PML
  - Daftar PCL

- 📝 **Data Survei**
  - Pengelolaan data kegiatan dan survei
  - Data mitra dan honor

- 💰 **Monitoring Honor**
  - Monitoring honor mitra
  - Filter berdasarkan bulan
  - Total honor setiap mitra
  - Identifikasi mitra yang melebihi batas honor
  - Detail monitoring honor

- ⚙️ **Pengaturan**
  - Informasi profil pengguna
  - Perubahan password
  - Pengaturan notifikasi
  - Pengaturan batas maksimal honor

- 🚪 **Logout**
  - Keluar dari sistem dengan aman melalui menu akun.
